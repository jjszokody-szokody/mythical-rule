# Mythical Rule

A medieval-fantasy kingdom game for iPhone and desktop (PWA).

- Name your kingdom and pick its colors, banner, emblem, religion and whether it is peaceful. Tap 🎨 any time to change the name or colors.
- ⚒ Customize (top right): build, move and remove buildings, plan your layout, assign jobs and create your own jobs.
- Pass laws and make royal decisions.
- Rival realms: three human kingdoms (stone, Northmen timber halls, desert sultanate), the Elves, the Dwarves, an Orc warband, the undead Rotlands and the demon Hellmouth.
- Mythical creatures: the dragon of Ember Peak, griffins, forest trolls and unicorns.
- A new scenario every 2–5 minutes, each with several choices.
- Months pass by themselves every 10 minutes. Each month every kingdom sends 3 tributes to the Arena. The winner's champion becomes Immortal.

Play: https://jjszokody-szokody.github.io/mythical-rule/ (on iPhone: Safari → Share → Add to Home Screen)

Built with three.js. Textures are CC0 (Poly Haven / ambientCG). Everything else, including the music, is procedural.
