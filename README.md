# Mythical Rule

A medieval-fantasy kingdom game for iPhone and desktop (PWA). Name your realm, choose its colors, religion and stance, lay out your city, pass laws, create jobs, survive scenarios, and send three tributes to the Arena every month (3 minutes). The winner's champion becomes Immortal.

Play: https://jjszokody-szokody.github.io/mythical-rule/ — on iPhone open in Safari → Share → Add to Home Screen.

Built with three.js. Textures CC0 (Poly Haven / ambientCG); everything else procedural.
